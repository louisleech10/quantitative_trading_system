## 為什麼長這樣

2026-09-20 之前是「**一票一份進度檔，每次進展往上疊一條**」。
那個模型必然產生四個症狀，你也逐一指出過：

| 症狀 | 為什麼必然發生 |
|---|---|
| 檔案多到難找 | 檔數隨票數線性成長（當時 26 份、17,549 行） |
| 找不到結論 | 往上疊 ⇒ 結論被埋（最嚴重那份 2,407 行、29 輪審查紀錄） |
| 不知還剩什麼 | 沒有跨票視角（殘留散在五個地方，沒一個是全的） |
| 新舊不分 | 沒有失效機制，舊條目永遠留著 |

現在改成「**每份只答一個問題，各有維護規則**」。
`Archived/` 裡是被取代的舊檔，留著備查，**不再維護、不用看**。
