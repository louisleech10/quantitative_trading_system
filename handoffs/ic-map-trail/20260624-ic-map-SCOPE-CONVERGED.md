# 分析類型全覆蓋地圖 — 範疇定案（SCOPE，三方收斂）

> 2026-06-24 ｜ Claude + codex + cursor 各提 scope → 本收斂版。Gemini 可選為第 4 家(待使用者授權)。
> 這是「地圖要涵蓋哪些分析類型 + 每條寫什麼」的定義；下一輪才填完整內容。

## 每條目的內容 schema（地圖每一格要寫的欄位，三方收斂）
1. **回答什麼問題**（白話，給非量化看懂）
2. **業界標準做法**（正確該怎麼算）
3. **平台現況**：標記 `[現有]` / `[部分]` / `[現有但壞掉]` / `[完全缺]` + **實際怎麼實作**（讀碼查證，例：多symbol是逐symbol還pool、event吃不吃顯式事件清單）
4. **做對沒 / 漏洞**（PIT、未來洩漏、train/test、時間軸…）
5. **430K欄×百symbol尺度怎麼做對又快**（接串流架構 CONVERGED.md）
6. **對應現有模組/檔案**
7. **優先級**（最高/高/中/低）

## 組織方式：按「你在問什麼研究問題」分群（非量化最易懂）

### A. 基礎預測力：這因子有沒有用？
| ID | 類型 | 回答什麼 | 現況 |
|---|---|---|---|
| A1 | 單標的時序 IC | 單一標的,因子今天值能否預測它自己未來報酬 | [現有] global |
| A2 | Rolling IC / IC 時間序列 | 預測力穩定還是只在某時段有效 | [現有] |
| A3 | ICIR (IC÷波動) | 預測力夠強且夠穩到值得用嗎 | [現有] |
| A4 | **Pooled/Panel 時序 IC（多symbol普適性）** | 把多symbol堆一起,pattern 是否普遍成立 | **[完全缺][高]** |
| A5 | symbol 一致性/普適性分析 | 每symbol各算IC,看正負/勝率/離群symbol | [部分] |
| A6 | 橫截面 IC | 同一時間點跨symbol,能否排序誰較強 | [現有] cross_sectional |

### B. 事件研究（你的主戰場）⭐
| ID | 類型 | 回答什麼 | 現況 |
|---|---|---|---|
| B1 | **Case-Control 事件研究（正/反案例+事件前窗）** | 正向事件發生前,特徵能否區分正vs反案例 | **[完全缺][最高]** |
| B2 | **事件前 lead-lag IC（event-time 對齊）** | 事件T前,哪些因子最早出現訊號(T-k→T-1) | **[完全缺][最高]** |
| B3 | 事件時點 IC | 只在事件當下bar,特徵與報酬有關嗎 | [完全缺][高] |
| B4 | **正反案例配對/matching/防洩漏** | 反案例要與正案例可比(同波動/regime),否則假陽性 | **[完全缺][最高]** |
| B5 | 事件前窗對齊 | 每事件取「發生前N根」對齊,非事件當根 | [完全缺][最高] |
| B6 | 事件 OOS / subtype 驗證 | 事件pattern須train/test,不能全事件挑因子 | [完全缺][最高] |
| B7 | 事件條件查詢 IC | 現況event_query只是過濾,不等於事件研究 | [現有但不足] |
| B8 | 訊號密度 (signal density) | 事件前後pattern在時間上多密 | [現有,另一模組] |

### C. 顯著性與穩健性：是真的還是運氣？
| ID | 類型 | 回答什麼 | 現況 |
|---|---|---|---|
| C1 | IC 顯著性 (t-stat/bootstrap CI) | IC大到不像隨機噪音嗎 | [部分] |
| C2 | **多重比較修正 (FDR/Bonferroni)** | 測43萬特徵,多少是假陽性 | **[需確認][高]** |
| C3 | block bootstrap / clustered SE | 處理時序自相關、同symbol群聚 | [完全缺] |
| C4 | 子樣本/跨時段穩定性 | 換時段/換symbol還成立嗎 | [部分] |

### D. 報酬結構與可交易性：賺得到嗎？
| ID | 類型 | 回答什麼 | 現況 |
|---|---|---|---|
| D1 | 分位/單調性 | 特徵越高報酬是否單調遞增 | [現有] |
| D2 | IC 衰減/半衰期 | 訊號多快失效,我有多少時間 | [現有但崩潰] |
| D3 | 多空因子報酬 | 做多高分賣空低分是否穩定賺 | [現有] |
| D4 | 換手/成本/net IC | 扣成本後還值得嗎 | [現有] |
| D5 | 容量/流動性/slippage 可行性 | 百symbol上實際下得了單嗎 | [完全缺或未主線] |

### E. 條件/狀態：什麼情況下有效？
| ID | 類型 | 回答什麼 | 現況 |
|---|---|---|---|
| E1 | regime/grouped IC | 牛熊/高低波/年季/category下是否有效 | [現有但崩潰] |
| E2 | symbol group/sector/liquidity bucket IC | 不同資產族群效果不同嗎 | [部分缺] |
| E3 | 時段 (time-of-day/session) IC | 加密/高頻常見時間結構 | [可選] |

### F. 因子互動與冗餘：是不是重複？
| ID | 類型 | 回答什麼 | 現況 |
|---|---|---|---|
| F1 | 相關/clustering/VIF | 因子是否只是同訊號換名字 | [現有] |
| F2 | 正交化/neutralized IC | 扣掉已知因子後還有新資訊嗎 | [現有,預設關] |
| F3 | 擁擠/centrality | 哪些是擁擠核心,哪些獨立 | [現有] |
| F4 | factor exposure | 訊號是不是其實只在押方向/波動 | [現有,預設關] |

### G. 非線性 / ML 視角：線性 IC 看不到的？
| ID | 類型 | 回答什麼 | 現況 |
|---|---|---|---|
| G1 | 模型驗證 IC (XGB/LGBM AUC) | 非線性關係存在嗎 | [現有引擎] |
| G2 | SHAP / 特徵重要性 | 模型認為哪些特徵真在驅動 | [部分] |

### H. 多因子組合：合起來更強嗎？
| ID | 類型 | 回答什麼 | 現況 |
|---|---|---|---|
| H1 | IC 加權組合 | 多個弱因子合成強訊號怎麼配權 | [待確認] |
| H2 | 組合層 IC/單調性 | 合成後經濟意義還在嗎 | [待確認] |

### I. 驗證與防洩漏（橫切所有分析）⭐
| ID | 類型 | 回答什麼 | 現況 |
|---|---|---|---|
| I1 | **train/test split** | 主IC路徑須只在train選因子、test驗證 | **[主路徑缺][最高]** |
| I2 | walk-forward / rolling OOS | 滾動訓練→驗證的泛化 | [現有模組] |
| I3 | purged / combinatorial purged CV | 事件重疊時CV標籤洩漏 | [現有 create_combinatorial_purged_cv] |
| I4 | 跨標的泛化 (A幣訓練B幣測試) | 換標的還有效嗎 | [部分] |

### J. 資料品質前置（算IC前的把關）
| ID | 類型 | 回答什麼 | 現況 |
|---|---|---|---|
| J1 | NaN/inf/常數偵測 | 沒變化的欄污染排名與相關矩陣 | [現有 gate] |
| J2 | 前處理影響審計 (winsor/zscore PIT) | 標準化是否用未來資訊/破壞streaming | [需審] |

## 優先級總覽（三方共識）
- **最高（你主戰場 + 正確性紅線）**：B1/B2/B4/B5/B6（事件 case-control 整套）、I1（train/test）。
- **高**：A4（pooled普適性）、C2（FDR）、D2/E1（修崩潰）。
- **中**：其餘現有但需 scale 化 / 預設關的。
- **低/可選**：E3、D5、G2 進階。
