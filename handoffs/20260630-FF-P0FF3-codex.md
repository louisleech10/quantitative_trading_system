- window：使用 `estimate_max_warmup_bars(config, primary_tf, training_tfs)`，不可手寫 2051；`window_bars >= warmup + trunc_k + post_warmup`。建議 `POST_WARMUP_BARS >= 48`，讓 4h/12h aligned columns 有足夠 both-non-NaN coverage。
- 截斷：primary 1h 真 kline bar 級 full/trunc end；比較 full 前 `n_trunc` vs trunc 全長，使用 B2 columns gate、both-non-NaN values gate、high-fill NaN mask gate、coverage guard、metadata gate。

## 對齊 mutation
- 注入點：優先 monkeypatch `TimeframeAligner.build_asof_index_map`，因 CGSA path 直接用它；legacy `align_to_primary` 也會經 searchsorted path。V-6 `test_before_baseline_shows_lookahead` 可作語義參考，但不能只複用固定 golden。
- mutation 內容：不要只改成 source close 的下一根；要 forward-open lookahead，例如 `idx = searchsorted(source_ts, primary_ts, side="right")`（越界填 -1 或 clip 皆可，但要與 trunc run 產生差異）。這模擬「用下一根粗 TF open bar」。
- 必須用邊界選窗：選 `full_end` 落在 12h open 邊界，`trunc_end = full_end - trunc_k*1h` 且 `0 < trunc_k < 12`（可沿用 10）。full run 會含 trunc run 沒有的下一根 12h source row；forward-open mutant 在 trunc 前綴靠近尾端會映到該 future row，表現為 12h/4h aligned 欄 values 或 NaN mask mismatch。
- mutation oracle：包 `with pytest.raises(AssertionError)` 跑同一 `_assert_truncation_invariants`；不要新增寬鬆 special oracle。若只檢 values 不紅，應檢查 sampled set 是否包含非 primary TF 欄，而不是放寬測試。

## 抽樣/覆蓋守衛
- B2 `_select_required_probe_columns` 需新增 alignment probes：至少一欄 `4h_` 與一欄 `12h_` 非 primary TF parquet/column；`_assert_mutation_layer_coverage` 加 `alignment(4h,12h)`。缺少即測試設計錯，fail。
- 對齊欄選擇優先 L1 raw-ish/high-fill 欄（例如 close/volume 類）以避免 near-empty informational mask 空轉；仍保留 B2 L3/L4/winsor probes。
- metadata gate 需額外 assert manifest/config_used 或 run metadata 的 `timeframes.training`/`present_timeframes` 含 `["1h","4h","12h"]`，防止退化成單 TF 假綠。

## 驗收命令

- 真 run 主驗收（長 timeout）：`pytest tests/feature_engineering/test_ff_multitf_truncation_mr.py -m requires_kline -q`
- mutation 必紅：同檔中 `test_mutation_mtf_forward_open_alignment_fails` 必須 PASS（內部捕捉 AssertionError）。

## 風險提醒
- 只用 `primary=12h, training=[1h,4h,12h]` 不是本題高頻截斷；那是粗主軸吸高頻，不足以替代 `primary=1h`。
- 任意尾窗可能讓 alignment mutant 假綠；mutation case 必須用 12h 邊界選窗。
- 不要跑慢全鏈作設計驗證；本腿只跑了 config/warmup 快速估算。
