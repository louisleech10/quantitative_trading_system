# 日誌系統改進方案

## 📋 問題分析（基於 First Principle）

### 核心問題
1. **調試訊息誤用 ERROR 級別** - 4處 `logger.error()` 用於 TRACE/DEBUG
2. **缺乏環境控制** - 調試日誌永久存在，無法按需開關
3. **日誌訊息不一致** - 中英文混雜，格式不統一
4. **缺乏結構化** - 無錯誤代碼，難以自動化分析

### 影響評估
- ❌ **日誌檔案充滿非錯誤訊息**（TRACE 被標記為 ERROR）
- ❌ **無法快速定位真正錯誤**
- ❌ **日誌檔案過大**（14MB/天，主要是調試訊息）
- ❌ **開發和生產環境無法區分**

## 🎯 改進方案（Ultra Think 三步驟）

### Step 1: 定義日誌級別體系

```
CRITICAL (50) - 系統崩潰、無法恢復
ERROR    (40) - 功能錯誤，需要人工介入
WARNING  (30) - 異常情況，但可自動恢復
INFO     (20) - 重要業務事件（生產預設）
DEBUG    (10) - 開發調試訊息
TRACE    (5)  - 詳細追蹤訊息（自定義）
```

### Step 2: 環境配置策略

| 環境 | LOG_LEVEL | ENABLE_DEBUG_LOGS | 輸出內容 |
|------|-----------|-------------------|----------|
| **生產** | INFO | False | 業務事件、警告、錯誤 |
| **開發** | DEBUG | True | + 調試訊息 |
| **追蹤** | TRACE | True | + 詳細追蹤 |

### Step 3: 日誌訊息分類

#### 🟢 INFO - 重要業務事件
```python
✅ "Starting search with 10 symbols"
✅ "Search completed. Found 287 cases in 41.6s"
✅ "Parallel processing enabled with 5 workers"
```

#### 🟡 WARNING - 可恢復異常
```python
✅ "No data available for SOLUSDT, skipping"
✅ "Cache miss for BTCUSDT, fetching from API"
✅ "Retrying failed request (attempt 2/3)"
```

#### 🔴 ERROR - 需要關注的錯誤
```python
✅ "Failed to fetch data for BTCUSDT after 3 retries: APIError(-1121)"
✅ "Search task failed: Invalid symbol format"
✅ "Database connection lost: ConnectionError"
```

#### 🔵 DEBUG - 開發調試（僅開發環境）
```python
✅ "Processing symbol: ETHUSDT (1/10)"
✅ "Found 5 initial candidates"
✅ "Applying filter: price_change >= 0.03"
```

#### 🟣 TRACE - 詳細追蹤（需手動開啟）
```python
✅ "market_class value: C5, type: str"
✅ "DataFrame shape: (100, 25)"
✅ "Memory usage: 2.5MB"
```

## 🎚️ 使用方式

### 生產環境
```bash
# .env
LOG_LEVEL=INFO
ENABLE_DEBUG_LOGS=false
ENABLE_TRACE_LOGS=false
```

### 開發環境
```bash
# .env
LOG_LEVEL=DEBUG
ENABLE_DEBUG_LOGS=true
ENABLE_TRACE_LOGS=false
```

### 問題追蹤（臨時開啟詳細日誌）
```bash
# 執行時動態開啟
curl -X POST http://localhost:8000/api/v1/admin/debug/enable
# 執行搜索...
curl -X POST http://localhost:8000/api/v1/admin/debug/disable
```

或通過環境變數：
```bash
LOG_LEVEL=TRACE ENABLE_TRACE_LOGS=true python run_api.py
```
