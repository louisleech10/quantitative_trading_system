# 歷史穩定度參數實作檢查清單

## 🎯 核心目標
在 `case_search_engine.py` 中新增5個「過去歷史」參數，用於過濾案例品質。

## 📋 實作步驟

### Step 1: 新增向量化計算函數
**位置**: `momentum/DataExtraction/case_search_engine.py`

新增函數:
```python
def calculate_past_features_vectorized(df, periods_24hr, periods_48hr, periods_72hr):
    """一次性計算5個歷史特徵（向量化）
    
    參數:
        df: 包含OHLCV數據的DataFrame
        periods_24hr: 24小時對應的bar數量（如12h timeframe = 2）
        periods_48hr: 48小時對應的bar數量（如12h timeframe = 4）  
        periods_72hr: 72小時對應的bar數量（如12h timeframe = 6）
    
    返回:
        添加了5個新列的DataFrame
    """
```

實作5個參數（使用 `.rolling()`）:
1. `past_24hr_max_single_move` = `df['return'].abs().rolling(periods_24hr).max()`
2. `past_48hr_price_range` = `(high最大 - low最小) / close * 100`
3. `past_72hr_avg_bar_volatility` = `df['return'].abs().rolling(periods_72hr).mean()`
4. `past_48hr_directional_movement` = `累積漲跌幅abs / 各bar漲跌幅abs總和`
5. `past_24hr_volume_stability` = `volume的std / volume的mean`

**關鍵**: 
- 必須向量化，不能用for循環
- 除法要加 `+ 1e-10` 避免除零

### Step 2: 整合到現有計算流程
**位置**: `_add_computed_columns()` 函數內

在計算完基礎參數後（price_change, volume_multiplier等），添加:

## ⚠️ 必須遵守的原則

### 1. 性能要求
- ✅ 使用pandas `.rolling()`  
- ❌ 禁止使用 `for i in range(len(df))`
- ✅ 目標: 10萬行 < 2秒

### 2. Timeframe適配
不同timeframe的bar數量對應:
| Timeframe | 24hr | 48hr | 72hr |
|-----------|------|------|------|
| 1h        | 24根 | 48根 | 72根 |
| 4h        | 6根  | 12根 | 18根 |
| 12h       | 2根  | 4根  | 6根  |
| 1d        | 1根  | 2根  | 3根  |

**獲取方式**: 使用 `self._get_timeframe_periods(timeframe)`

### 3. 除零保護
所有除法操作必須加保護:
```python
result = numerator / (denominator + 1e-10)
```
