## 1. 手動驗證指南（圖形界面操作）

這是一份**完全圖形化**的操作指南，即使完全不懂程式碼，也能獨立完成驗證。

### 1.1 環境準備（首次使用必做）

#### 步驟 1: 啟動後端服務器

1. **打開終端（Terminal）**
   - Mac: 按 `Cmd + Space`，輸入 "Terminal"，按 Enter
   - Windows: 按 `Win + R`，輸入 "cmd"，按 Enter

2. **進入專案目錄並啟動後端**
   ```bash
   # 複製以下整段命令，貼到終端，按 Enter
   cd /Users/louis/Desktop/quantitative_trading_system
   python -m uvicorn api.main:app --reload --port 8000
   ```

3. **驗證後端啟動成功**
   - ✅ **成功標誌**: 看到以下訊息
     ```
     INFO:     Uvicorn running on http://127.0.0.1:8000
     INFO:     Application startup complete.
     ```
   - ❌ **如果失敗**:
     - 檢查錯誤訊息，可能是 port 8000 被佔用
     - 解決方式: 改用 `--port 8001`

4. **保持此終端窗口開啟**（不要關閉）

---

#### 步驟 2: 啟動前端開發服務器

1. **打開新的終端視窗**
   - Mac: 按 `Cmd + N`（在 Terminal 中）
   - Windows: 再次打開 cmd

2. **進入前端目錄並啟動**
   ```bash
   # 複製以下命令，貼到新終端，按 Enter
   cd /Users/louis/Desktop/quantitative_trading_system/frontend
   npm run dev
   ```

3. **驗證前端啟動成功**
   - ✅ **成功標誌**: 看到以下訊息
     ```
     ▲ Next.js 14.x.x
     - Local:        http://localhost:3000
     - Network:      http://192.168.x.x:3000

     ✓ Ready in 2.5s
     ```
   - ❌ **如果失敗**:
     - 錯誤訊息包含 "npm: command not found"
       - 解決: 需要先安裝 Node.js
     - 錯誤訊息包含 "Cannot find module"
       - 解決: 執行 `npm install`，然後重試

4. **保持此終端窗口開啟**（不要關閉）

---

#### 步驟 3: 打開瀏覽器

1. **推薦瀏覽器**: Chrome 或 Edge（避免使用 Safari）

2. **前往網址**: `http://localhost:3000`

3. **驗證頁面載入**
   - ✅ 應該看到系統首頁
   - ❌ 如果看到「無法連接」，檢查前端是否啟動成功

### 1.2 功能驗證清單（逐步操作）

以下每個測試案例都是**獨立的**，可以按順序執行。

#### 測試案例 1: 創建優化任務 ⭐⭐⭐（核心功能）

**目標**: 驗證能夠成功創建並啟動 Optuna 優化任務

**步驟**:

1. **導航到策略測試頁面**
   - 點擊左側選單的「Strategy Test」
   - 或直接在瀏覽器輸入: `http://localhost:3000/strategy-test`

2. **選擇正例案例（Positive Cases）**
   - 找到標題為「Positive Cases」的區域
   - 勾選至少 **10 個案例**（建議 15 個）
   - ✅ **驗證點**: 右上角顯示「15 selected」

3. **選擇反例案例（Negative Cases）**
   - 找到標題為「Negative Cases」的區域
   - 勾選至少 **10 個案例**（建議 15 個）
   - ✅ **驗證點**: 右上角顯示「15 selected」

4. **配置 Optuna 優化設定**
   - 找到「Optuna 參數優化設定」折疊面板（Accordion）
   - 點擊展開
   - 切換「啟用優化」開關為 **ON**
   - 設定以下參數（測試用小規模）:
     - **Trial 次數**: `20` ← 重要！測試用小數字
     - **超時時間**: `300` 秒（5 分鐘）
     - **隨機種子**: `42` ← 可重現結果
     - **啟用剪枝**: `ON`
   - ✅ **驗證點**: 所有設定值正確顯示在輸入框中

5. **配置參數搜索空間（可選）**
   - 保持預設值即可，或自訂:
     - EMA Short: 5-15
     - EMA Mid: 20-40
     - EMA Long: 50-100
   - ✅ **驗證點**: 無警告訊息（如「short_max >= mid_min」）

6. **啟動優化**
   - 滾動到頁面底部
   - 點擊「開始優化」按鈕
   - ✅ **驗證點 1**: 按鈕變為「優化中...」且不可點擊
   - ✅ **驗證點 2**: 出現進度條（初始 0%）
   - ✅ **驗證點 3**: 顯示「預估剩餘時間」（ETA）

7. **監控進度（約 3-5 分鐘）**
   - 觀察進度條每隔 3-5 秒更新
   - 觀察「最佳值」數值逐漸改善
   - ✅ **驗證點 1**: Trial 數量遞增（1/20 → 2/20 → ... → 20/20）
   - ✅ **驗證點 2**: 進度百分比遞增（5% → 10% → ... → 100%）
   - ✅ **驗證點 3**: ETA 逐漸減少

8. **等待完成**
   - 當 Trial 達到 20/20 時
   - ✅ **驗證點 1**: 顯示「優化完成」綠色訊息
   - ✅ **驗證點 2**: 出現「查看結果」按鈕
   - ✅ **驗證點 3**: 顯示最終最佳參數

**預期結果**:
- 優化成功完成 20 次 Trial
- 無錯誤訊息
- 耗時約 3-5 分鐘

## 4. 常見問題排除

### 4.1 後端啟動失敗

**問題**: 執行 `uvicorn` 命令時報錯

**解決方案 1**: Port 被佔用
```bash
# 檢查 port 8000 是否被佔用
lsof -i :8000

# 如果被佔用，殺掉該進程
kill -9 <PID>

# 或改用其他 port
python -m uvicorn api.main:app --reload --port 8001
```

**解決方案 2**: Python 模組未安裝
```bash
# 安裝依賴
pip install -r requirements.txt
```

---

### 4.2 前端啟動失敗

**問題**: 執行 `npm run dev` 時報錯

**解決方案 1**: Node.js 未安裝
```bash
# 檢查 Node.js 版本
node --version

# 如果未安裝，前往 https://nodejs.org/ 下載安裝
```

**解決方案 2**: 依賴未安裝
```bash
# 安裝依賴
cd frontend
npm install
```

**解決方案 3**: Port 3000 被佔用
```bash
# 檢查 port 3000
lsof -i :3000

# 或在 package.json 中修改 port
# 將 "dev": "next dev" 改為 "dev": "next dev -p 3001"
```

---

### 4.3 優化無法啟動

**問題**: 點擊「開始優化」後無反應

**檢查清單**:

3. ✅ 參數範圍是否重疊？
4. ✅ 瀏覽器控制台是否有錯誤？（按 F12 查看）

**解決方案**: 打開瀏覽器控制台（F12），查看錯誤訊息，並報告給開發人員。

---

### 4.4 圖表不顯示

**臨時解決方案**: 重新整理頁面（Ctrl+R / Cmd+R）
