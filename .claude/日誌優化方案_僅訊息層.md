### 2️⃣ 優化：改善錯誤訊息可讀性

**檔案**: `momentum/DataExtraction/case_search_engine.py`

#### 行 513（真正的錯誤）
```python
# Before
self.logger.error(f"Error searching single symbol {symbol}: {str(e)}")

# After
self.logger.error(f"[SEARCH_FAILED] Symbol: {symbol} | Error: {type(e).__name__}: {str(e)}")
```
**目的**: 加上錯誤標籤 `[SEARCH_FAILED]` 和錯誤類型，方便我快速過濾和定位

#### 行 477（參數錯誤）
```python
# Before
self.logger.error(f"Failed to add calculated columns for {symbol}")

# After
self.logger.error(f"[CALC_FAILED] Symbol: {symbol} | Failed to add calculated columns")
```

#### 行 412（儲存失敗）
```python
# Before
self.logger.error(f"Failed to save results: {save_error}", exc_info=True)

# After
self.logger.error(f"[SAVE_FAILED] Failed to save search results: {type(save_error).__name__}: {str(save_error)}", exc_info=True)
```

### 3️⃣ 優化：改善 INFO 訊息簡潔性（使用者友好）

**檔案**: `momentum/DataExtraction/case_search_engine.py`

#### 行 372-374（搜索開始）
```python
# Before
self.logger.info(f"Starting search with config: {config.name}")
self.logger.info(f"Symbols: {symbols}")
self.logger.info(f"Time range: {config.start_time} to {config.end_time}")

# After（合併為一行）
self.logger.info(f"Search started: {len(symbols)} symbols, {config.start_time} to {config.end_time}")
```
**目的**: 減少日誌行數，使用者只需知道「開始搜索 X 個交易對」

#### 行 404（搜索完成）
```python
# Before
self.logger.info(f"Search completed. Found {len(all_results)} cases")

# After
self.logger.info(f"Search completed: {len(all_results)} cases found")
```
**目的**: 統一訊息格式

#### 行 427, 434, 436（處理進度）- 改為 DEBUG
```python
# Before
self.logger.info(f"Processing symbol: {symbol}")
self.logger.info(f"Found {len(symbol_results)} cases for {symbol}")
self.logger.info(f"No cases found for {symbol}")

# After（改為 DEBUG，減少生產環境輸出）
self.logger.debug(f"Processing {symbol}: {len(symbol_results)} cases found")
# 或
self.logger.debug(f"Processing {symbol}: no cases found")
```

### 4️⃣ 優化：並行搜索日誌

**檔案**: `momentum/DataExtraction/parallel_search_engine.py`

#### 減少重複的進度日誌（改為條件式）
```python
# Before (每個 symbol 都輸出)
logger.info(f"Processing symbol: {symbol}")

# After (每 10% 或每批次才輸出)
if batch_idx % max(1, total_batches // 10) == 0:
    logger.info(f"Progress: {batch_idx}/{total_batches} batches ({batch_idx/total_batches*100:.0f}%)")
```

#### 改善失敗訊息
```python
# Before
logger.error(f"批次處理失敗: {e}", exc_info=True)

# After
logger.error(f"[BATCH_FAILED] Batch {batch_idx}/{total_batches} failed: {type(e).__name__}: {str(e)}", exc_info=True)
```
