#     一直缺一枚戳記；補簽了也**不被採信**，因為 provenance 要求審計中有指向
#     被戳記檔本身的 `committee_output` 事件，而該檔不在 `handoffs/` 底下 ⇒ 註冊不了。
#   · ⇒ canonical Rule 2/3/4 的 scanner 自 2026-07-14 起 fail-closed 在戳記關卡，
#     **一行程式碼都沒掃過**；07-15～07-22 有 21 個 commit 打進它守的那些檔，

# ── 為何是清單而不是放寬前綴 ────────────────────────────────────────
# 放寬成「任何路徑都能註冊」＝把 provenance 的錨點交給呼叫者自由指定。
# 本專案已四次因**未封閉的 glob／前綴**被三家否決（見 GOV_MECHANISM_REGISTRY）。
# ⇒ 本檔只收**完整路徑字面值**：
#     · 不接受萬用字元（含 `*`、`?`、`[`）
#     · 不接受目錄前綴（結尾 `/`）
#     · 不接受 `..`
#   違反者 `gate.sh` 直接 fail-closed，不是略過該列。
#
# ── 誠實邊界 ────────────────────────────────────────────────────────
