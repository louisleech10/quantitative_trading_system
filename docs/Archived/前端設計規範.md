# 前端設計規範：Liquid Glass Dark (Refined Lite)

## 1. 設計概述 (Design Overview)

本專案採用 **"Liquid Glass Dark" (液態玻璃深色模式)** 風格。
核心目標是建立一個**高對比度、低視覺疲勞、且具有通透感**的量化交易儀表板。

**關鍵修正 (Critical Refinement)：**

* **字重輕量化**：嚴格控制字體粗細。除極少數大標題外，**禁用粗體 (Bold)**。以 `font-normal` (400) 和 `font-medium` (500) 為主，營造精細的科技感。
* **高對比數據色**：在深色背景上，必須使用高亮度的螢光色系（Emerald-400, Rose-400）以確保可讀性。

---

## 2. 色彩計畫 (Color Palette)

請更新 `tailwind.config.ts` 的主題設定，採用以下色碼：

### 基礎色系 (Base Colors)

* **Background (深邃背景)**: `#0A0F1C` (帶有極微量藍色的深黑，非純黑)
* **Glass Surface (玻璃基底)**: `#1a233a` (需搭配 Opacity 使用)
* **Glass Border (玻璃邊框)**: `rgba(255, 255, 255, 0.08)` (極淡白光)

### 狀態指示色 (Status Colors - High Visibility)

*請務必使用以下高亮度色碼，避免使用預設的暗紅/暗綠。*

* **Success (漲/正樣本)**: `#34d399` (Tailwind `emerald-400`)
* **Danger (跌/負樣本)**: `#fb7185` (Tailwind `rose-400`)
* **Warning (警告)**: `#fbbf24` (Tailwind `amber-400`)
* **Primary (主色)**: `#60a5fa` (Tailwind `blue-400`)

### 文字顏色 (Typography Colors)

* **Text Main**: `#f1f5f9` (Slate-100)
* **Text Muted**: `#94a3b8` (Slate-400)

---

## 3. 字體與排版規則 (Typography Rules)

**⚠️ 重要規則：全面輕量化 (Weight Reduction)**

所有組件預設不得使用 `font-bold` (700) 或 `font-extrabold` (800)。請依照以下層級設定字重：

* **KPI 大數字 (Big Numbers)**:
* 使用 `font-semibold` (600) 或 `font-medium` (500)。
* *禁止使用 font-extrabold。*


* **卡片標題 (Card Headers)**:
* 使用 `font-medium` (500)。
* 搭配文字顏色 `text-white` 或 `text-slate-100` 即可區分層級，無需加粗。


* **正文/標籤 (Body/Labels)**:
* 使用 `font-normal` (400) 或 `font-light` (300)。
* 次要資訊使用 `text-muted`。

## 4. 元件樣式規範 (Component Styles)

請在 `globals.css` 中定義以下 Utility Class，以便全域重複使用：

### A. 液態玻璃面板 (`.glass-panel`)

這是所有卡片 (Card) 的標準樣式：

```css
.glass-panel {
  @apply bg-[#1a233a]/40;        /* 40% 透明度的深藍底 */
  @apply backdrop-blur-xl;       /* 強力背景模糊 */
  @apply border border-white/10; /* 極細微的白邊框 */
  @apply shadow-2xl shadow-black/20;
}

```

### B. 發光圖表線條 (`.chart-glow-line`)

用於 SVG 折線圖，製造「光劍」般的效果：

```css
.chart-glow-success {
  filter: drop-shadow(0 0 4px rgba(52, 211, 153, 0.5)); /* Emerald-400 Glow */
}
.chart-glow-danger {
  filter: drop-shadow(0 0 4px rgba(251, 113, 133, 0.5)); /* Rose-400 Glow */
}

```

### C. 漸層背景氛圍 (`body` 背景)

為了突顯玻璃效果，Body 必須有微弱的光暈背景：

```css
body {
  background-color: #0A0F1C;
  background-image: 
    radial-gradient(at 0% 0%, rgba(56, 189, 248, 0.1) 0px, transparent 50%),
    radial-gradient(at 100% 100%, rgba(99, 102, 241, 0.1) 0px, transparent 50%);
  background-attachment: fixed;
}

```

## 5. 圖表視覺化修正 (Chart Visualization)

針對 Recharts 或 SVG 圖表的具體要求：

1. **網格線 (Grid Lines)**:
* 顏色：`#ffffff` (白)
* 透明度：`0.05` (極淡)
* 樣式：`dashed` (虛線)


2. **區域填充 (Area Fill)**:
* 使用 `LinearGradient`。
* 從頂部的 `opacity: 0.5` 到底部的 `opacity: 0`。


3. **機率密度圖 (Density Plot)**:
* 正樣本區域：使用 `Emerald-400` 漸層。
* 負樣本區域：使用 `Rose-400` 漸層。
* **重疊區域**：利用透明度讓兩者自然混合，不要使用實心色塊覆蓋。
