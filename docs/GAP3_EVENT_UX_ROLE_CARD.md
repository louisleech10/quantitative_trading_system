## 🔴 scope accretion 之入口閘（R12 三家裁定；CODEX-R12 議題二 Q7）

使該判斷**可被下一輪逐條覆核**。

**不得先落地再於 brief 附帶問**——須先以 consult／brief 取得裁定。

⚠️ **具名殘留（做不成機械閘；R14 codex 明列）**：目前**沒有任何閘**能在
「新增 transport／producer／receipt／encoder／parallel fixture 或改 owner／shape」時當場攔截
——`gap3ux_pre_review.sh` 只跑既有常駐閘與 optional locus。

**入口閘（寫死；本卡生效即適用，含委員之補丁包**與主委之落地**）**：

1. **一個 Task 只能有一個可執行 owner。** 該 Task 已有 owner 時，新增要求**只能擴充該 owner

   parallel fixture。
2. **機制入 SPEC 之前置**：若一個新機制無法在**同一份補丁包**內同時提供
   **owner ／ shape ／ consumer ／ negative mutation ／ SYNC-LOCI** 五者，
   **該機制不得進入 SPEC**。
3. 🔴 **這是入口閘，不是刪 Task 的授權**——不得援引本節縮範圍
   （使用者已裁 42 個一個不砍）。

## 🔴 補丁包 anchor 之寫法（R12 議題一裁定＝維持現行判準，責任講白）

三家裁定**不改判準**（主委已 3/3 改判準引入新洞；候選 (a) 前後 N 行、(b) 行號區間
皆被否決——前者假綠面更大、後者行號會漂）。**改的是委員的寫法責任**：

- anchor 應指向**會被改動／已寫入的那一行之字面**，
  **不要**只錨段落標題或段落指標（例如「五階段（固定順序…）」）。
- 若意圖是**刪除**某句，就錨**被刪除之字面**（走弱證據路徑，並在 BEFORE/AFTER 提及它）。
- 範例：
  `- docs/GAP3_EVENT_UX_SPEC.md#coverage 之輸出寫回 \`PreparedAnalysisWindows.allowed_event_ids\`；@spec`
- 🔴 **「anchor 指到未改動之段落標題」明確歸為委員責任**，不算主委漏套。

## 委員之新交付物：補丁包（R9 增訂 stage 後綴與 anchor 字面閘）

檔名：`handoffs/patches/<日期>-<epic>-<輪次>-<cluster>.md`

```markdown
# PATCH cluster <名>
AUTHORITY: <哪一處是權威定義>
SYNC-LOCI:
- <檔>#<可 grep 到的字面錨點>            # 缺 stage 後綴 ⇒ 預設 @spec
- <檔>#<字面錨點>@doc                    # 白話說明／角色卡等
- <檔>#<字面錨點>@harness                # 治理腳本／測試
- <檔>#<字面錨點>@impl                   # 實作階段才會動到的產品程式碼
BEFORE/AFTER: <可直接套用之替換或 unified diff>
VERIFY:
- <可跑之命令>
```

🔴 **anchor 必須是字面（R9 裁定；三家一致）**：`patch_locus_check.py` 於 parse 當下即
以「該 anchor 是否出現在該檔**當前內容**」判定，找不到 ⇒ **補丁包格式錯，rc=2**。
R8 曾有敘述型 anchor（`#檔頭 A-6／FROZEN 句`／`#§A-A-6`／`#§G-G-2`）——
那些字串在檔內根本不存在 ⇒ 實質改完了閘仍紅，且紅得沒有資訊。

🔴 **stage 是補丁包之責任宣告，不是呼叫端的降噪開關（R9 三家裁定）**：
未達之 `@impl` 列為 **DEFERRED、不計 rc**（凍前不實作）；
呼叫端只有 `--also-impl` 這個**加寬**旗標，**不得**新增任何「只檢查某 subset」之旗標。
缺省 stage ＝ `@spec`（最嚴）⇒ 忘了標的行為與 R8 完全相同，不放寬。
⚠️ 誠實邊界：委員若把 spec locus 誤標 `@impl`，本閘看不見 ⇒ 與 anchor 精確度同類，
屬委員責任，保留獨立審查（見下「做不成機械閘者」）。

🔴 **commit 後複驗須帶 `--diff-base <套用前 ref>`**：對乾淨 worktree 跑無 base 之檢查，
會把**已落地**之 locus 誤報為「檔案未被本次改動」——那是方法論假紅。

**責任歸屬（三家明訂）**：
- 補丁包**漏列** locus ⇒ **補丁包紅，算委員責任**，不算主委自傷。
- 已列而主委**未改齊** ⇒ 主委套用不完整，補改後重跑。
