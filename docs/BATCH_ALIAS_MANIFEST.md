# 批次別名（batch_alias）Phase 1+2 Manifest（2026-06-16）

> 來源：使用者決策「Phase 1+2」+ 設計委員會 Codex（handoffs/20260616-batch-alias-design-codex.md）。
> 問題：批次 N symbol → N runs（各 config_hash），逐一改名 100 次。目標：命名整批一次。

- [BA-1] batch_id 參數鏈(V4,Codex r1-B1+r2-B1+r3-B1):batch_id 非既有 context,**顯式參數穿透,禁用 self._current_batch_id mutable state(r2-B1:隱式 context 跨呼叫污染/不可審)**。鏈:batch execute loop(`_process_item_wave` 由 checkpoint["batch_id"] 取,非 task_id)→`_compute_single(...,batch_id)`(ProcessPool picklable str)→`generate_features(...,batch_id=None)` 新參數。**三 helper 顯式加 batch_id 參數,且兩條生成路徑都要穿透(r3-B1:真實 kline 是 multi-TF=主路徑)**:① 單 TF:generate_features(@367)`_layer7_raw_from_cgsa_pipeline(...,batch_id)`(內 @3373 再傳)`_layer7_validate_and_persist_cgsa(...,batch_id)`、(@400)`_layer7_validate_and_persist(...,batch_id)`;② **multi-TF:generate_features(@306)`generate_multi_tf(...,batch_id)`(新參數)→multi_tf_generator.py 內三呼叫 `self._factory._layer7_raw_from_cgsa_pipeline`(:309/:600)、`_layer7_validate_and_persist`(:1364)都傳 batch_id**→registry.add 三處(:3197/3342/3474)用區域參數寫入。單 run batch_id=None。舊 entry .get 向後相容。
- [BA-2] batch_alias 不覆寫 per-run alias;**同 run 多批語義(V3,Codex r1+r2-MAJOR):三態(r4 釐清):同 batch_id 再生保留 batch_alias;換 batch_id(!=)→overwrite+reset;傳入 None→merge-preserve**;**「傳入 batch_id=None(單 run 再生同 key)」不 overwrite→merge-preserve 既有 batch_id/batch_alias(r2-MAJOR#1:單 run 再生不偷剝批次歸屬)**。顯示優先序 `alias > batch_alias:{symbol} > symbol/timeframe/hash`。
- [BA-3] PATCH 批次別名端點：`PATCH /api/v1/features/batch/{batch_id}/alias` body {batch_alias}，依 registry `batch_id` 更新同批所有 runs 的 batch_alias（registry transaction，回 affected runs 數）；batch_id 查無對應 entry→**404 `batch_not_found`(定死,非 affected-0,Codex r1-MAJOR)**。**set_batch_alias 對 deleting entry 對齊 set_alias:任一 target deleting→raise RunBusyError(API 409)整筆 fail,不部分更新(r2-MAJOR#2)**。
- [BA-4] 唯一性：per-run alias 維持同 (symbol,tf) 內唯一（不變）；batch_alias 以 batch_id 為主（同 batch_id 一致），允許不同 batch 重名（顯示用 batch_id/時間 disambiguation），不與 per-run alias 唯一性衝突。
- [BA-5] auto-cleanup 保護(V2,Codex r1-B2):**候選 filter 與 `mark_deleting()` transaction 都改 `not (alias or batch_alias)`**——僅改候選不夠,mark_deleting 仍只檢 alias 會與 set_batch_alias race 後誤清;兩處一致(run_lifecycle.py auto_cleanup:145+mark_deleting)。
- [BA-6] Feature Explorer：RunInfo 加 batch_id/batch_alias；formatRunLabel 顯示優先序 [BA-2]；搜尋 haystack 加入 batch_alias(**filteredRuns 在 FeatureExplorer.tsx 非 runExplorer.ts**,Codex r1-MAJOR);selection key 不變（symbol/tf/config_hash）。
- [BA-7] Run 管理分組（Phase 2）：按 batch_id/batch_alias 分組顯示；提供「重命名整批」一鍵（呼叫 [BA-3]）；per-run rename 保留作 override；無 batch 的 run 維持單列。
- [BA-8] 測試：後端 batch_id 寫入 registry + PATCH batch alias 更新整批 + auto-cleanup 保護 batch_alias + 唯一性；前端 formatRunLabel 優先序 + 搜尋 batch_alias + Run 管理分組/整批 rename vitest。防假綠不放寬既有斷言。
- [BA-9] 不做（Phase 3，另議）：一等 batch entity（batches.json）；本批 batch_id/batch_alias 存在 run registry，checkpoint 仍只做 resume。
- [BA-10] 流程：中-大（命中 (b) registry 共用路徑+auto-cleanup lifecycle）；Composer 實作+Codex review；SPEC 經 Codex adversarial（跨家族，Composer 實作）→ 過 gate 派工；CGSA/數值路徑不動（純 metadata）。
