## §0 範圍（**先讀這節，它決定哪些 finding 不受理**）

**本程序只擋意外，不防蓄意。**

| | 在範圍內 | 不在範圍內 |
|---|---|---|
| 要擋的 | 漏記、抄錯、忘了同步、改了沒人知道 | 有人蓄意偽造 git 物件、繞過檢查器、竄改歷史 |
| 依據 | 這些**在本 repo 實際發生過**（見 §4） | 這些**一次都沒發生過** |

**⇒ 凡屬「蓄意繞過」類的問題，一律列入 §4 記錄，不在本程序內解決。**
若日後真的發生，屆時帶著事故證據處理。

## §1 兩種修訂

| 類別 | 定義 | 做法 |
|---|---|---|
| **D 延伸** | 不推翻既有設計的修訂——含錯字、交叉引用、補充 | 寫延伸檔；延伸檔取得三家戳記。**對原檔的唯一允許改動＝§3 的索引行**，其餘一律不動 |
| **R 重開** | 既有設計被證偽 | 原檔重跑完整對抗審，原戳記作廢 |

**判定**：主委在 brief 明示類別與理由；任一委員可推翻；**爭議一律預設 R**。
**沒有第三類，沒有免審類別。**

## §2 延伸檔必填

路徑：`docs/<原檔 basename>.D-<NNN>.md`，`<NNN>` 為該原檔的延伸流水號，從 `001` 起，**不重用**。

```
# <原檔名> 延伸 D-<NNN>

BASE: <原檔路徑> @ <commit-sha>
PREDECESSOR: <前一份生效中的延伸檔路徑，或 none>
改什麼: <一句話>
為什麼: <一句話，或指向 reconcile 路徑>

## 觸及面宣告
新增: <原檔中實際存在的 heading 逐字，或 none>
覆寫: <同上，或 none>
依賴: <同上，或 none>

## 內容
<實際的修訂內容>

## 戳記

> 三家 RECONCILE-STAMP；body sha256 = 「## 戳記」前全部內容。
```

- `BASE` 的 commit-sha 用 `git rev-parse HEAD` 取，**寫下當時的值**
- **觸及面宣告的錨點必須是原檔中實際存在的 heading 逐字**〔`CODEX-R7-P1-02`：
  範例若用不存在的錨點，審查者無法完成對讀，會把未觸及的面誤判為 D〕。無則寫 `none`，**不得留空**
- **`## 戳記` 區必填**〔`GROK-R7-P1-01`：`reconcile_stamps_check.sh` 在缺該標題時直接 FAIL，
  照舊模板產出的檔無法通過 §3 機檢〕
- **觸及面宣告**是給審查者對讀用的：他必須去看原檔那幾個 heading，確認沒有互斥
- **若發現與原檔互斥 ⇒ 那不是 D，是 R**

## §3 戳記與下游引用

### 3.1 取得戳記前必須先做（**用既有工具，不新增檢查器**）

〔`CODEX-R7-P0-01` [BLOCKING]：只要求三家戳記而不要求保存各家產物與 completeness，
**手動綜合漏掉一家的 finding 仍可取得三戳記**。這已經發生過兩次：
手動 reconcile 漏 grok `T1-01`、IC merge 漏約 15 項。**屬「不用蓄意就會發生」，在受理範圍內。**〕

若該延伸檔是委員審查的產物：
1. 各家產出**逐字保存**於 `handoffs/reconcile/<session>/sources/`，用 canonical 四欄格式
2. `bash scripts/completeness_check.sh --lock <session>/sources.lock` **rc=0**
3. 零 finding 的家族須產**恰一條 `P3-00` sentinel**（不得空手）
4. 然後才 append 戳記

### 3.2 戳記
- 延伸檔須取得**三家 RECONCILE-STAMP**，機檢 `bash scripts/reconcile_stamps_check.sh <檔>` rc=0

### 3.3 生效集合與下游引用（**人工義務，現有工具不機檢**）

〔`CODEX-R7-P1-03`、`GROK-R7-P1-03`：兩份平行 D 可同時取得三家戳記並覆寫同一 heading，
造成無蓄意的契約分叉〕

- 每份 D 須在 `PREDECESSOR` 指明它接在哪一份之後（第一份寫 `none`）
- **兩份 D 的觸及面重疊（覆寫同一 heading）⇒ 不得平行生效，須升 R**
- 下游（TODO／brief／派工）引用時，**同時列出原檔與所有生效中的延伸檔**
- 原檔檔頭加一行索引：`延伸: D-001 <路徑>, D-002 <路徑>`
  （**這是 §1 允許的唯一原檔改動**）
- R 一旦裁定 → 該原檔的所有延伸檔一併失效，**且須同時清空原檔檔頭的索引行**，重新來過

⚠️ **本節全部是人工義務。** 現有工具**不會**檢查「下游有沒有列全延伸檔」，
也**不會**檢查「兩份 D 是否重疊」。漏了不會有紅燈。
