## 🎯 為什麼需要 XGBoost？

### 你的系統流程

```
Optuna 找參數 → 得到「高分指標組合」→ XGBoost 分析 → 找到「起漲前模式」→ 建立策略
```

### Optuna vs XGBoost 的差別

| 工具 | 做什麼 | 白話解釋 |
|-----|--------|---------|
| **Optuna** | 找最佳參數組合 | 像是找到「RSI < 30 且 MACD 黃金交叉」這種規則 |
| **XGBoost** | 找更深層的模式 | 在符合上述規則的情況下，進一步分析「哪些額外特徵會讓勝率更高」 |

### 舉例說明

假設 Optuna 找到一個策略：「當 RSI < 30 時買入」，勝率是 55%。

但你會發現，並不是每次 RSI < 30 都會漲：
- 有時候買了就漲（賺錢）
- 有時候買了繼續跌（虧錢）

**XGBoost 的任務**就是幫你找出：「RSI < 30 的情況下，還有什麼特徵可以區分『會漲』和『會跌』？」

結果可能是：
- RSI < 30 + **成交量放大 2 倍** + **價格在 20 日均線附近** → 80% 會漲
- RSI < 30 + 成交量萎縮 + 價格遠離均線 → 只有 40% 會漲

這樣你就可以只交易第一種情況，把勝率從 55% 提升到 80%！

## 🌳 XGBoost 是什麼？用生活例子解釋

### 一句話解釋

**XGBoost = 一群專家投票決定結果**

### 生活例子：判斷明天會不會下雨

想像你要判斷明天會不會下雨，你可以問不同的「專家」：

**專家 1（只看雲量）**：
- 如果雲量 > 80% → 會下雨
- 如果雲量 < 80% → 不會下雨

**專家 2（只看氣壓）**：
- 如果氣壓 < 1010 hPa → 會下雨
- 如果氣壓 > 1010 hPa → 不會下雨

**專家 3（只看風向）**：
- 如果是東南風 → 會下雨
- 如果是其他風向 → 不會下雨

單獨問每個專家，準確率可能只有 60%。

但如果你**同時問 100 個專家，然後投票**：
- 70 個說會下雨，30 個說不會 → 最終判斷「會下雨」
- 這樣準確率可能提升到 85%！

### XGBoost 就是這樣運作

- 每個「專家」在 XGBoost 裡叫做一棵「**決策樹**」
- XGBoost 會自動建立很多棵決策樹（通常 100~1000 棵）
- 每棵樹看不同的特徵組合
- 最後綜合所有樹的意見，得出最終預測

### 套用到你的交易系統

**你的問題**：「這個 K 線之後會漲還是會跌？」

**XGBoost 做的事**：
1. 收集歷史資料（幾千根 K 線的特徵）
2. 標記每根 K 線之後「漲了」還是「跌了」
3. 建立 100 棵決策樹，每棵樹學習不同的模式
4. 遇到新的 K 線時，讓 100 棵樹投票
5. 告訴你「這根 K 線之後有 75% 機率會漲」

## ⚙️ XGBoost 如何運作？

### 簡化版流程

```
步驟 1: 準備資料
    ↓
    收集歷史 K 線，計算各種指標
    例如：RSI、MACD、成交量、布林通道位置...
    
步驟 2: 標記答案
    ↓
    每根 K 線之後，價格漲了標記 1（賺錢），跌了標記 0（虧錢）
    
步驟 3: 訓練模型
    ↓
    XGBoost 分析「什麼特徵組合」會導致「漲」或「跌」
    建立很多棵決策樹
    
步驟 4: 驗證效果
    ↓
    用模型沒看過的資料測試，看預測準不準
    
步驟 5: 輸出結果
    ↓
    告訴你哪些特徵最重要，以及預測的準確率
```

### 決策樹長什麼樣？

想像一棵樹是這樣判斷的：

```
                    [RSI < 30?]
                    /          \
                  是            否
                  ↓             ↓
           [成交量 > 2倍?]    [價格 > 上軌?]
            /        \         /        \
          是         否       是        否
          ↓          ↓        ↓         ↓
        漲(80%)    跌(55%)  跌(70%)   不確定(50%)
```

這棵樹學到的規則是：
- RSI < 30 且成交量放大 → 很可能漲
- RSI < 30 但成交量沒放大 → 可能跌
- RSI > 30 且價格突破上軌 → 可能跌（過熱）

XGBoost 會建立很多這樣的樹，每棵樹可能從不同角度切入。

## 📊 關鍵指標解讀 - 判斷模型好不好

當你看到 XGBoost 的分析報告，會有很多指標。以下教你如何解讀：

### 1. AUC（曲線下面積）

**白話解釋**：模型區分「會漲」和「會跌」的能力

| AUC 值 | 意義 | 白話說法 |
|--------|------|---------|
| 0.50 | 跟猜硬幣一樣 | 完全沒用 |
| 0.60 | 略好於猜測 | 有點用，但很弱 |
| 0.65 | 有一定區分能力 | 可以用，但要謹慎 |
| 0.70 | 不錯的模型 | 值得信賴 |
| 0.75+ | 很好的模型 | 相當可靠 |
| 0.90+ | 太好了，要懷疑 | 可能有問題（資料洩漏） |

**舉例**：
- AUC = 0.68 → 模型有 68% 的機率能正確區分漲跌，比猜測好 18%

### 2. Train AUC vs CV AUC

| 指標 | 意義 |
|------|------|
| **Train AUC** | 用「學習資料」測試的分數（像是考自己出的題目） |
| **CV AUC** | 用「沒看過的資料」測試的分數（像是考別人出的題目） |

**重點：看 CV AUC，不是 Train AUC！**

**舉例**：
- Train AUC = 0.85，CV AUC = 0.65 → **過擬合**（死記硬背，沒有真的學會）
- Train AUC = 0.72，CV AUC = 0.68 → **健康**（真的學會了）

### 3. AUC Gap（訓練與驗證的差距）

**計算**：AUC Gap = Train AUC - CV AUC

| AUC Gap | 意義 | 行動建議 |
|---------|------|---------|
| < 0.05 | 非常健康 | 可以信任這個模型 |
| 0.05 ~ 0.10 | 輕微過擬合 | 可以用，但要注意 |
| 0.10 ~ 0.15 | 中度過擬合 | 需要調整模型 |
| > 0.15 | 嚴重過擬合 | 不要用這個模型 |

**舉例**：
- Train AUC = 0.75，CV AUC = 0.70，Gap = 0.05 → ✅ 健康
- Train AUC = 0.90，CV AUC = 0.65，Gap = 0.25 → ❌ 嚴重過擬合

### 4. CV AUC Std（穩定性）

**意義**：模型在不同時間段的表現是否一致

| CV AUC Std | 意義 |
|------------|------|
| < 0.03 | 非常穩定 |
| 0.03 ~ 0.05 | 穩定 |
| 0.05 ~ 0.08 | 有些波動 |
| > 0.08 | 不穩定，可能只在特定行情有效 |

**舉例**：
- CV AUC Mean = 0.68，Std = 0.02 → 模型穩定，可信
- CV AUC Mean = 0.68，Std = 0.10 → 模型不穩定，可能只在牛市有效

### 5. 盈利樣本比例

**意義**：在所有預測為「會漲」的樣本中，實際上漲的比例

| 比例 | 意義 |
|------|------|
| < 50% | 虧錢的比賺錢的多 |
| 50% ~ 55% | 打平或小賺 |
| 55% ~ 60% | 有優勢 |
| > 60% | 顯著優勢 |

### 6. 樣本數量

**意義**：模型學習的資料量

| 樣本數 | 意義 |
|--------|------|
| < 500 | 太少，結果不可靠 |
| 500 ~ 1000 | 勉強可用 |
| 1000 ~ 3000 | 適中 |
| > 3000 | 充足，結果可信 |

### 指標組合判斷表

| 情況 | CV AUC | AUC Gap | 樣本數 | 結論 |
|------|--------|---------|--------|------|
| 🟢 理想 | > 0.65 | < 0.08 | > 1000 | 可以使用 |
| 🟡 謹慎 | 0.60~0.65 | 0.08~0.12 | 500~1000 | 需要更多驗證 |
| 🔴 避免 | < 0.60 或 > 0.90 | > 0.12 | < 500 | 不建議使用 |

## 🔍 特徵重要性 - 哪些指標最有用

### 什麼是特徵重要性？

XGBoost 會告訴你：「在預測漲跌時，哪些指標最有幫助」

**舉例**：假設模型輸出的特徵重要性是：

| 排名 | 特徵 | 重要性分數 |
|------|------|-----------|
| 1 | RSI_14 | 0.25 |
| 2 | Volume_Ratio | 0.18 |
| 3 | MACD_Histogram | 0.15 |
| 4 | BB_Position | 0.12 |
| 5 | EMA_Slope | 0.10 |
| ... | ... | ... |

這表示：
- RSI 是最重要的指標，貢獻了 25% 的預測能力
- 成交量比例是第二重要的
- MACD 柱狀圖是第三重要的

### 三種重要性指標

| 指標 | 意義 | 白話說法 |
|------|------|---------|
| **Gain** | 該特徵帶來的預測改善 | 「這個指標讓預測變準多少」 |
| **Cover** | 該特徵影響的樣本數 | 「這個指標影響了多少筆交易」 |
| **Frequency** | 該特徵被使用的次數 | 「這個指標被用了幾次」 |

**建議**：主要看 **Gain**，它最直接反映預測能力。

### 如何使用特徵重要性？

**策略 1：聚焦重要特徵**

如果 RSI 是最重要的特徵，你的策略應該以 RSI 為核心：
- 不要只看 RSI < 30
- 要看 RSI 的具體數值、變化速度、停留時間等

**策略 2：刪除無用特徵**

如果某個特徵重要性 < 0.01（1%），可能是噪音：
- 考慮從策略中移除
- 減少過度擬合的風險

**策略 3：組合重要特徵**

前三名特徵通常應該一起考慮：
- RSI + 成交量 + MACD 的組合可能比單看 RSI 更準

## 🎯 決策規則解讀 - 模型學到了什麼

### 什麼是決策規則？

決策規則是 XGBoost 學到的「如果...那麼...」邏輯。

**舉例**：模型可能學到以下規則：

```
規則 1：
如果 RSI < 25 且 成交量 > 前 5 日平均的 1.5 倍
→ 預測「會漲」（信心度 75%）

規則 2：
如果 RSI > 75 且 價格 > 布林上軌 且 MACD 柱狀圖轉負
→ 預測「會跌」（信心度 80%）

規則 3：
如果 價格 在 20 日均線附近（±1%）且 成交量萎縮
→ 預測「盤整」（信心度 60%）
```

### 如何找到這些規則？

雖然 XGBoost 內部有上百棵樹，但可以總結出關鍵規則：

**方法 1：看特徵重要性 + 閾值**

如果報告顯示：
- RSI_14 重要性最高
- 常見的分割點是 RSI = 30 和 RSI = 70

那麼你可以推斷：「RSI 的超買超賣區域是關鍵」

**方法 2：看 SHAP 值（如果有提供）**

SHAP 值會告訴你：
- 某個特徵讓預測「偏向漲」還是「偏向跌」
- 例如：RSI < 30 時，SHAP 值為正（偏向漲）

### 決策規則的實際應用

假設模型告訴你這些規則很重要：

| 條件 | 預測 | 信心度 |
|------|------|--------|
| RSI < 30 + 放量 | 漲 | 75% |
| RSI < 30 + 縮量 | 跌 | 55% |
| RSI 30~70 | 不確定 | 50% |

**你的策略應該是**：
- ✅ 只在「RSI < 30 + 放量」時進場
- ❌ 避開「RSI < 30 + 縮量」的情況
- ❌ 避開「RSI 30~70」的模糊區域

## 💰 如何用分析結果建立高期望值策略

### 期望值公式複習

```
期望值 = (勝率 × 平均獲利) - (敗率 × 平均虧損)
```

**舉例**：
- 勝率 60%，每次賺 100 元，虧 80 元
- 期望值 = (0.6 × 100) - (0.4 × 80) = 60 - 32 = **28 元**

### 策略建立流程

```
步驟 1: 選擇好模型
    ↓
    挑選 CV AUC > 0.65、AUC Gap < 0.10、樣本 > 1000 的模型
    
步驟 2: 找出關鍵特徵
    ↓
    看特徵重要性，找出前 3~5 名的指標
    
步驟 3: 萃取決策規則
    ↓
    理解「什麼條件下」模型預測會漲，信心度多高
    
步驟 4: 設定進場條件
    ↓
    只在「高信心度」的情況進場
    
步驟 5: 設定出場條件
    ↓
    根據模型的預測期望報酬設定停利停損
```

### 實戰範例

**情境**：你有一個 XGBoost 模型，分析結果如下：

| 指標 | 數值 |
|------|------|
| CV AUC | 0.68 |
| AUC Gap | 0.07 |
| 樣本數 | 2500 |
| 盈利樣本比例 | 58% |

| 特徵排名 | 特徵 | 重要性 |
|----------|------|--------|
| 1 | RSI_14 | 0.22 |
| 2 | Taker_Buy_Ratio | 0.18 |
| 3 | Volume_Change | 0.14 |

**Step 1: 判斷模型品質**

- CV AUC = 0.68 ✅（> 0.65）
- AUC Gap = 0.07 ✅（< 0.10）
- 樣本 = 2500 ✅（> 1000）

結論：這是一個可用的模型。

**Step 2: 理解關鍵特徵**

- RSI 最重要 → 超買超賣是關鍵
- 主動買入比例 → 買盤力道很重要
- 成交量變化 → 量能也是關鍵

**Step 3: 建立策略規則**

根據特徵組合，建立進場條件：

```
進場條件（全部滿足）：
1. RSI_14 < 35（超賣區）
2. Taker_Buy_Ratio > 55%（買盤主導）
3. Volume_Change > 1.2（成交量放大 20%）

出場條件：
- 停利：+5%
- 停損：-2.5%
- 時間停損：持有超過 10 根 K 線未達停利則出場
```

**Step 4: 計算期望值**

假設回測結果：
- 符合條件的交易次數：150 次
- 勝率：62%（93 次獲利）
- 平均獲利：4.2%
- 平均虧損：2.1%

期望值 = (0.62 × 4.2%) - (0.38 × 2.1%) = 2.6% - 0.8% = **1.8%**

每次交易的期望報酬是 1.8%，這是一個正期望值策略！

### 提升期望值的技巧

| 技巧 | 說明 |
|------|------|
| **提高勝率** | 只交易信心度最高的訊號（可能減少交易次數） |
| **提高盈虧比** | 讓平均獲利 > 平均虧損（調整停利停損） |
| **增加過濾條件** | 用更多特徵組合過濾假訊號 |
| **避開特定行情** | 在模型表現差的市場狀態（如震盪市）不交易 |

## ❓ 常見問題 FAQ

### Q1: AUC 越高越好嗎？

**不一定。** 

- AUC > 0.90 要懷疑是否有「資料洩漏」（用到了未來資訊）
- 實務上，0.65~0.75 的 AUC 就很不錯了
- 更重要的是 AUC Gap 要小（代表沒有過擬合）

### Q2: 為什麼 Train AUC 很高，CV AUC 很低？

**過擬合。**

模型「死記硬背」了訓練資料，但沒有學會真正的規律。

就像學生背了所有考古題，但遇到新題目就不會。

**解決方法**：
- 減少模型複雜度
- 增加訓練資料
- 刪除不重要的特徵

### Q3: 特徵重要性低的指標要刪掉嗎？

**看情況。**

- 重要性 < 1% 的特徵通常可以刪除
- 但有時候多個低重要性特徵組合起來可能有用
- 建議先刪除最低的幾個，看看 AUC 有沒有下降

### Q4: 模型說會漲，但實際上跌了，怎麼辦？

**這是正常的。**

- 即使 AUC = 0.70 的好模型，也有 30~40% 的錯誤率
- 重要的是「長期下來」正確率 > 錯誤率
- 單次虧損不代表模型有問題

**關鍵是**：
- 嚴格執行停損
- 不要因為一次虧損就放棄策略
- 累積足夠的交易次數讓統計優勢顯現

### Q5: 模型的預測機率要怎麼用？

**設定門檻。**

假設模型輸出「75% 機率會漲」：

| 門檻策略 | 進場條件 | 交易次數 | 勝率 |
|----------|----------|----------|------|
| 寬鬆 | 機率 > 50% | 多 | 較低 |
| 中等 | 機率 > 60% | 中等 | 中等 |
| 嚴格 | 機率 > 70% | 少 | 較高 |

建議從「中等」開始，再根據實際結果調整。

### Q6: 多久要重新訓練模型？

**市場會變化，模型會過時。**

建議：
- 每 1~3 個月檢視模型表現
- 如果最近一個月的勝率明顯下降（比如從 60% 降到 50%），考慮重新訓練
- 市場發生重大變化時（如政策改變、牛熊轉換）要重新訓練

### Q7: 怎麼知道模型在牛市還是熊市比較有效？

**分開測試。**

把資料分成：
- 牛市期間（價格上漲超過 20%）
- 熊市期間（價格下跌超過 20%）
- 震盪市（其他時期）

分別計算每個時期的 AUC，看看模型在哪種市場最有效。

**常見情況**：
- 有些模型只在牛市有效（容易做多賺錢）
- 有些模型只在熊市有效（擅長抓反彈）
- 最好的模型在各種市場都有一定效果

## 📋 快速檢查清單

拿到 XGBoost 分析結果後，按這個順序檢查：

### ✅ 模型品質檢查

- [ ] CV AUC > 0.65？
- [ ] AUC Gap < 0.10？
- [ ] CV AUC Std < 0.05？
- [ ] 樣本數 > 1000？
- [ ] AUC 不是異常高（< 0.90）？

### ✅ 特徵檢查

- [ ] 前三名特徵是什麼？
- [ ] 這些特徵在邏輯上說得通嗎？
- [ ] 有沒有異常特徵（不應該出現但很重要）？

### ✅ 策略建立

- [ ] 根據重要特徵設定進場條件
- [ ] 設定停利停損
- [ ] 計算期望值是否為正
- [ ] 決定在什麼市場狀態使用

## 🎓 總結

| 概念 | 一句話總結 |
|------|-----------|
| **XGBoost** | 一群決策樹投票，找出漲跌的模式 |
| **AUC** | 模型區分漲跌的能力，0.65+ 就不錯 |
| **AUC Gap** | 訓練和驗證的差距，越小越好（< 0.10） |
| **特徵重要性** | 告訴你哪些指標最有用 |
| **決策規則** | 模型學到的「如果...那麼...」邏輯 |
| **期望值** | 長期下來每次交易的平均獲利 |

**記住最重要的事**：

1. **不要追求完美的 AUC**，0.65~0.75 就很好
2. **AUC Gap 比 AUC 本身更重要**，Gap > 0.10 的模型不要用
3. **特徵重要性幫你聚焦**，前幾名的指標是策略核心
4. **正期望值才是目標**，勝率高 + 盈虧比好 = 賺錢
5. **模型會過時**，定期檢視和更新
