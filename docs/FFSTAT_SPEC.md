## §C 約束
- **逐欄檢定**：開啟 fracdiff 或 ADF 差分時，進入該步驟之每欄皆以其校準值做 ADF 判定；不設任何免檢清單。名稱不得參與任何平穩化之判定。刪 `utils/adf_safe_skip.py` 之判定用途與 `ADFSafeSkipConfig`（含 `additional_patterns`／`exclusion_patterns`）；設定帶此段 ⇒ 設定驗證拒收並指名已移除。
- **目標層**：fracdiff 目標層（L1、L2，寫死）只取自結構化層來源——frame 路徑 `_column_layer_map`、CGSA 路徑群組之 `layer`；對照缺欄或無對照 ⇒ fail-closed（指名缺漏欄數與示例）；刪 `_FRACDIFF_LAYER_RE` 欄名解析退路。
- **`apply_to` 封閉**：`ADFDifferencingConfig.apply_to` 與 `FractionalDifferencingConfig.apply_to` 只收 `non_stationary`、`all`；regex、欄名清單、`layer1_only` 於設定驗證拒收（訊息指名只收二值）；刪 `_select_columns` 之 `layer1_only` 分支。winsor、rank 等縮放步驟不在本票（§N）。
- **校準資料無洩漏**：ADF 差分候選、fracdiff 目標篩選、d\* 搜尋三路之校準值，只取**該 symbol、該原生週期、輸出起始日之前**之資料（每欄最後 N 個有效值，N＝校準長度），且該段不進入公開輸出與任何切分。無起始日時（v32）改依「未填起始日」：各欄以逐欄穩定點後之最早 N 個有效值校準，該 N 列於公開輸出遮為 NaN。所稱「有效值」一律指套用下條逐欄穩定點遮罩後之有限值。
- **逐欄穩定點**（v32；使用者 2026-09-27 裁定 R1、R3、R4、R6）：適用於一切生成——有無起始日、平穩化開關、frame／CGSA 序列／CGSA 平行／resume／`run_ic_first` 自算路徑、公開域與校準域皆同。
  - **L1 遮罩**：每個 L1 指標之各輸出欄，自「該指標全部輸入欄皆為有限值之第一列」（origin）起之前 K 列（列索引 `[origin, origin+K)`，依該指標原生週期實際存在之列計，缺口不補）於計算當下設為 NaN；K **逐計算呼叫**決定（v37；取代 v32 之「max_period 沿用 `_resolve_indicator_max_period`」——該值為整個指標之最大週期，會使 EMA_5 亦遮 336 列，違反 R3）：K＝ceil(該次呼叫之已解析參數字典中、倍數表對該指標登記之 `period_keys` 各值之最大者 × 倍數表係數)；無參數指標取表內登記之 K。v46（R10 實測根數優先）：條目另存 `k_by_params`——鍵＝該次呼叫之 `period_keys` 各鍵值依鍵名升序以 `鍵=值` 逗號連接（值為整數字面），值＝該組參數跨 5 週期、3 標的實測 K 之最大（某週期該組量測不可信〔量得 K > 前史／2〕時以該週期之係數×該組最大週期補，無條件進位）；呼叫之鍵查得者 K 取其值，查無者才用上式（未量過之參數組合以比例公式作保守上限）。起因：KAMA（內部固定 2／30 平滑常數）與 MACDFIX（內部固定 逗號連接（整數寫整數字面）；條目登記已量測之非週期參數變體 `variants`（v48：已量測＝收據中有已收斂量測者；預熱估算之查表與遮罩同一變體檢查；週期參數為序列〔如 MAVP 之 periods〕時以序列最大值計 K、正規鍵以 `[a|b|…]` 表示），呼叫之非週期參數組合（含無參數指標如 MAMA 之 fastlimit）未量測 ⇒ 輸出前 fail-closed（`UnmeasuredVariantError`，列引擎、欄與未量測之組合；R5 精神，不以推估值放行；反例 MA matype=4 實測 258 > 233）；②`k_by_params`、係數與無參數 K 皆取**已收斂**量測（含前史 < 2K 之不可信者——其量得 K 仍為收斂所需之實測下界）之最大，某週期該組無已收斂量測時才以該週期係數×週期補；採用值不得低於收據中任一已收斂量測（反例 DX／ADA／1d／144 實測 1,138 > 表 1,035），以收據對表之逐筆不變量測試守。遮罩於 L1 各輸出點套用——TA-Lib 指標於 L2 或跨引擎合併前，逐**輸出欄**提供「產生該欄之參數字典」與倍數表之 `period_keys`（多輸出指標如 BBANDS、MACD 之各欄共用該次呼叫之字典；多窗迴圈之引擎逐欄建立對應，如 microstructure 以既有 `get_feature_metadata` 之欄級參數）；自訂指標定義須逐輸出宣告其 period keys，否則於輸出前 fail-closed；缺字典或缺鍵 Consensus），K＝上游輸出 K 之最大者＋本步窗長−1（窗型）或上游輸出 K 之最大者（逐點聚合），其 metadata 須帶上游之已解析參數（如 VPIN z-score 帶 base bucket 與 sigma bucket），取不到即輸出前 fail-closed；②`CustomIndicatorDef` 新增必填 `outputs` 宣告（輸出欄名 → 已解析參數與 period_keys），`CustomIndicatorEngine.compute_all` 於 concat 前驗回傳欄集合＝宣告集合，無宣告或不相等即 blocked（設定格式變更；預設 `custom_indicators: []`〔`config/scan_config.yaml:593`〕，無現行設定受影響）。L1 輸出點之集合以 AST
