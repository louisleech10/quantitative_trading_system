- [B2-1] Run identity 與 canonical resolver：config_hash opaque token（`^[A-Za-z0-9_.-]{1,64}$` 非全 `.`）；features=feature_run_dir 委派；cgsa=抽自 feature_factory.py:903-912；新增 `safe_token()` 共用 sanitize（lock 檔名與 cgsa 同用 re.sub 規則，Composer #6/Codex Gate1 統一）；pass2/browse stable_id 一律**完整 hash**（hash8 碰撞，Codex #7）。
- [B2-2] Per-run lease（**V5 終局：fcntl.flock**，Codex r3/r4-N1 兩輪證明自製接管協定有 successor-race/無 base case 後轉向）：lock 檔=`data_cache/features/.locks/{safe_s}_{safe_tf}_{full_hash}.lock`，`flock(LOCK_EX|LOCK_NB)`；kernel 互斥+**進程死亡自動釋放**（stale/接管/graveyard/age 門檻整段不存在）；lock 檔永不 unlink（unlink/open 競態）；lease 可跨執行緒移交（coordinator release）；`is_run_active`=try-flock 探測；前提=data_cache 本機磁碟（§N）。
- [B2-3] Registry transaction：`_locked_mutate`（指數退避自旋 10ms 起 ×2 上限 500ms、總 30s，逾時 raise **`RegistryLockTimeout`**（≠RunBusyError，Composer #10））；add merge-preserve；**corrupt 時 add 不落盤**（in-memory only + 保留 `registry.json.corrupt-<ts>` 副本供人工救援，禁空表覆寫——Codex #12 partial 收斂）；lifecycle mutation/cleanup corrupt → fail-closed。
- [B2-4] 刪除一致性（**V3：Codex N2/Composer #5**）：內核 `_delete_run_locked(s,tf,h,lease)`（caller-holds-lease）；`delete_run`=acquire→內核；`auto_cleanup`=逐候選 acquire→**`_locked_mutate` 內 re-check alias 並標記 entry `deleting:true`**→內核→最終 remove；**`set_alias` 也 acquire run lease（timeout=0，busy→409）且拒 `deleting:true` entry**——alias/刪除全程由 lease+transaction 雙重序列化；cgsa ownership=manifest 完整 hash 核對；override env 不刪明示。
- [B2-5] lease 生命週期接線（**V3 凍結介面，Codex N3/Composer #2**）：`generate_features`（feature_factory.py:209，config_hash 確定處 ~:236-243）與 **`run_ic_first_pipeline`**（~:1860，V2 寫 `generate_and_persist` 為虛構名，Composer #1 勘誤）acquire；新參數 `lease_sink: Optional[list] = None`——成功且 sink 非 None → 不 release、append lease handle；失敗→factory finally release。service 傳 sink，warmup daemon thread `finally`：release → auto_cleanup → 流程結束（completed event 照現行時點發送，順序文檔化）。batch worker 不傳 sink（無 warmup，factory 自管）。
