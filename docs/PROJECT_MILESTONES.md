### 關鍵技術決策

| 決策項 | 選擇 | 原因 | 替代方案 |
|--------|------|------|---------|
| 後端框架 | FastAPI | 高性能、自動文檔、類型檢查 | Flask（功能少）、Django（過重） |

| 配置格式 | YAML | 可讀性好、支持註釋 | JSON（無註釋）、TOML（少用） |
| 圖表庫 | Recharts | React友好、配置簡單 | Chart.js、ECharts |

### 解決的關鍵問題

#### 問題 1: 搜索結果狀態持久化
- **現象**: 頁面跳轉後搜索結果消失
- **根因**: 使用組件本地狀態（useState）
- **解決**: 遷移到 Zustand 全局狀態管理
- **影響**: 改善用戶體驗，避免重複搜索
- **完成日期**: 2025-09-28

#### 問題 2: 反例採樣質量不足
- **現象**: 反例數量不足且質量不一致
- **根因**: 時間分離條件過嚴（7天）、未考慮市場環境
- **解決**: 調整為 3 天時間窗口、實現分層採樣
- **影響**: 提升採樣質量，確保正反例分布合理
- **完成日期**: 2025-08-10

#### 問題 3: 大數據處理性能問題
- **現象**: 搜索速度慢，內存占用高
- **根因**: 使用 DataFrame.iterrows()、一次性加載所有數據
- **解決**: 向量化操作、分批處理
- **影響**: 性能提升 10 倍，內存占用降低 60%
- **完成日期**: 2025-08-05

#### 問題 4: CORS 跨域問題
- **現象**: 前端無法訪問後端 API
- **根因**: 前後端運行在不同端口
- **解決**: 配置 CORS 中間件
- **影響**: 前後端正常通信
- **完成日期**: 2025-08-25

#### 問題 5: CSV 導出中文亂碼
- **現象**: 導出的 CSV 在 Excel 中顯示亂碼
- **根因**: 默認 UTF-8 編碼
- **解決**: 使用 UTF-8 with BOM 編碼
- **影響**: 完美支持中文導出
- **完成日期**: 2025-09-25
