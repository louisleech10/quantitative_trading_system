同一輪還被抓到我的驗算式本身有洞：那個式子是「拿序號去索引，看取出來的值對不對」，而 Python 的負數索引會從尾巴倒數，所以序號寫成 -1 時，取出來的值剛好對得上，錯的資料就這樣通過了。修法是在索引之前先檢查「是整數、落在範圍內、不重複、而且遞增」。
