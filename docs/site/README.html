為什麼「清單」花掉一整天

清單（技術版叫 TODO）是寫給實作端照著做的施工說明書，裡面每一條驗收都會變成閘門。 閘門寫錯的代價不是慢，是它會亮綠燈但什麼都沒擋——那比沒有閘門更糟，因為後面的人會信它。

委員抓到 白話

層 時機 行為
