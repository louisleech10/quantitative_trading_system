Task 這是做什麼（白話） 誰要的 不做會怎樣 決定

🔴 1.9／1.10／1.11／1.12 這四個是「衍生」：你那 10 個問題裡沒有這件事。 源頭是你打斷我改文案那次——你說「預測未來幾根會漲跌也是一種 scenario，不能寫死」。 我把它通則化成「要隔多遠 ＝ 你的標籤引用到最遠第幾根」，委員再推翻我原本的偵測方案、 逼出三層防線。這四個是本批最重的技術債，也是最沒跟你確認過的。

你可以怎麼砍

參考幾種砍法（不是建議，是選項）：

  • 只留你直接要的 20 個 → 規格會小很多，但洩漏防線（1.9–1.12、2.1b）會一起砍掉， 意味著「答案窗隔多遠」變成你自己負責，系統不擋。

  • 全留 → 就是現在這 42 個，繼續派審查輪。
