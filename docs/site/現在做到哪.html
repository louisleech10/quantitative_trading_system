🔴 卡住的原因：我給你看的例子是錯的

我在方向說明裡寫「你可以寫 EMA_5 > EMA_10，這是多頭排列」。

在實際資料上，那個條件永遠成立——20,294 根全部命中、一段都不分。

真因：存檔的特徵已經被轉換過（fracdiff），而且每個週期轉的程度不一樣：

欄 實際內容
EMA_5 ～ EMA_34 各自被轉換不同程度
EMA_50 ～ EMA_144 被轉成「變動量」
EMA_200、EMA_233 完全沒轉換（還是價格）

所以 EMA_5（約 208）跟 EMA_10（約 124）比大小，比的是兩個不同尺度的東西，沒有意義。 14 個現有的 run 全都是這樣。⇒ 這就是為什麼要重跑一個沒轉換的。
