這輪審查抓到、且值得你知道的事

第2批（21 條，三家一致「修完可進第3批」，沒有一條要重做；分歧只在嚴重度，一律取較嚴的那版，全部這輪修、不留待辦）：

  1. 我對自己程式碼的描述是錯的：我在派工單上寫「年化夏普那種列我算進『壞列』」，三家實跑都證明程式其實沒有算進壞列（那是合法列，只是不進 DSR）。而且三家一致判定：清單裡那句「年化列要算壞列」本身就寫錯了（合法枚舉不該當非法）。程式對、我的說法錯、清單字面錯 ⇒ 延伸檔 A1-21 把那句作廢，測試加了「壞列數＝0」的明確斷言鎖住。
  2. 同一筆可能被記兩次：唯一性檢查是「先讀再寫」，兩個行程同時寫就都會通過（Grok 硬逼出來重現了）。Codex 另抓到「可以把 A 帳本的列寫進 B 帳本」。修：寫入前上檔案鎖＋帳本身分必須相符；並做成「拿掉鎖就一定變紅」的測試。
  3. NaN 可以寫進帳本、還會被 DSR 拿去算：三家中兩家抓到。修：寫入和讀取兩端都擋。
  4. 快照 hash 會撞：用 | 拼接三段字串，段落裡若有 | 就撞（三家各給一組反例）。修：改 JSON 定界，反例全數變成不撞。
  5. 我自認最可疑的地方，三家確認確實是洞：帳本路徑怎麼算的那段程式，之前所有測試都把它整個換掉，等於沒測過。修：新增一檔測試走真路徑，改個目錄名就紅。
  6. 其他：讀契約檔多／少鍵不再靜默放行、型別檢查改精確比對（Enum／numpy 冒充一律拒）、快取改成外面改不到、錯誤訊息會說缺哪個多哪個。

第3批（12 條，三家一致「修完可進第4批」；全部這輪修）：

  1. API 錯誤分類有洞（兩家 MAJOR）：reporter 若丟出一般 ValueError，路由會把它當「用戶輸入錯」回 400；而「接線 bug」那類雖然回 500，訊息卻被外層再包一層。修：reporter 路徑的錯一律 500、訊息固定字面、外層不再重包；補測試。
  2. 失敗還留垃圾（兩家抓到，我 brief 沒列）：路由先把 pipeline 檔寫進磁碟、再呼叫 reporter，reporter 一報錯就留下一個孤兒檔。修：reporter 先跑（它只讀不寫），失敗就不落盤；測試斷言目錄空。
  3. 驗收字面「skew=0、kurt=3」我沒真的固定住（兩家）：我用對稱序列讓 skew 恰為 0，但峰度是樣本值 2.68 不是 3。修：另造一個峰度恰為 3 的序列（十字型：±s 各 n 個加 4n 個 0），先斷言矩再斷言 DSR 等於閉式 PSR——原本那條保留當第二道鎖。
  4. 測試用的假帳本違反帳本自己的不變式（兩家）：修成由構造滿足。
  5. n_source 三個字面沒住進契約（Grok；Composer 也建議）：加進契約枚舉（頂層鍵 16→17，延伸檔 A1-22 覆寫「恰 16」），loader 的機械枚舉對映自動接管、寫入端也驗。
  6. 我用 sed 多插了一行沒用的 import（Codex）：同一個模式命中兩處，我沒先 grep -c。已刪；本 epic 第二次同型錯，寫進收斂檔。

第4批（13 條，三家一致「修完可收工」；全部這輪修）——這批我先自己在延伸檔（A1-23）列了七項「可能不忠於清單字面」的地方請委員裁決，結果三項被推翻、四項可接受：

  1. 接線閘的「放行名單」太寬（兩家 MAJOR，各給反例）：我為了讓「傳遞既有 reason」不被誤擋，放行了任何 x.某屬性／x["某鍵"]；Grok 實跑證明可以用 reason=data["x"] 塞自創字面繞過。修：收窄成只認 .reason／["reason"]／.get("reason", …)／同函式範圍的變數；補 5 條反例測試（全部變紅）＋正例。另外「死枚舉」判定也太寬（只在註解或沒用到的常數裡出現也算接線）——修成必須真的用在 reason 位置或被引用。
  2. PBO 排名的分母我改了定義（Codex P1 引原始論文）：我用「樣本外也算得出來的候選」當分母，論文與清單字面都是「該路徑全部有效候選」。修：守字面；任何候選樣本外算不出來就整條路徑跳過，不在縮小的母體上排名。
  3. 退化計數重複算（兩家）：冠軍在樣本外退化時我 +1 了兩次。修：每候選每路徑最多 +1，測試改精確斷言。
  4. 雙冠測試是廉價綠燈（三家一致，我 brief 也自承）：修成手算可證偽——平手時取小索引 ⇒ ω=ln(2/3)，取大索引 ⇒ ln 4，測試鎖 1e-12。
  5. 向量化夏普與原函式在「幾乎常數」的欄會給不同的天文數字（兩家）：修成逐欄用同一個一維算法 ⇒ 逐位相同；順帶暴露第 1 批 compute_sharpe 對這種序列不當退化——第 1 批已蓋章的語意，登記殘留 G1-R11（要研究容差怎麼定）。
  6. golden 檔的防改 sha 只掛在一個測試檔（Grok）：抽成唯一 loader，三檔測試都經它驗。
