## 設計目標

### First Principles分析

**核心需求**：使用者需要像在TradingView上一樣查看案例的K線圖，判斷案例質量，並看到策略信號標記。

**關鍵問題**：
1. 如何讓使用者快速定位到案例時間點T？
2. 如何清楚標示T點和策略信號？
3. 如何提供流暢的圖表互動體驗？
4. 如何同步顯示多個圖表（Price/Volume/Taker_Ratio）？

**設計原則**：
- 清晰優先：一眼看出關鍵資訊
- 流暢體驗：60fps渲染目標
- 靈活操作：支援拖曳、縮放、重置
- 專業外觀：類似TradingView的專業感

## 整體UI架構

### 頁面佈局設計

**三欄式佈局**：

```
┌────────────────────────────────────────────────────┐
│              頂部導航列（固定）                     │
├──────────┬─────────────────────────────────────────┤
│          │                                          │
│  案例    │          圖表區域                        │
│  列表    │    ┌──────────────────────────┐         │
│  側邊欄  │    │  圖表控制面板            │         │
│          │    └──────────────────────────┘         │
│  (30%)   │                                          │
│          │    ┌──────────────────────────┐         │
│          │    │  Price K線圖             │         │
│          │    │  (含案例標記、信號箭頭)  │         │
│          │    └──────────────────────────┘         │
│          │                                          │
│          │    ┌──────────────────────────┐         │
│          │    │  Volume 柱狀圖           │         │
│          │    └──────────────────────────┘         │
│          │                                          │
│          │    ┌──────────────────────────┐         │
│          │    │  Taker Ratio 線圖        │         │
│          │    └──────────────────────────┘         │
│          │                                          │
│  (70%)   │                                          │
└──────────┴─────────────────────────────────────────┘
```

**響應式調整**：
- 桌面版（>1280px）：三欄佈局
- 平板版（768-1280px）：側邊欄可收合
- 手機版（<768px）：全屏圖表，側邊欄改為抽屜

### 佈局理由

**左側案例列表**：
- 使用者需要快速切換案例
- 顯示關鍵資訊（symbol、時間、timeframe、標籤）
- 勾選框支援批量操作

**右側圖表區域**：
- 最大化圖表顯示空間
- 三個圖表垂直堆疊，時間軸對齊
- 預留控制面板空間

## 案例列表設計

### 列表項內容

每個案例顯示：

```
┌────────────────────────────┐
│ ☑ ETHUSDT              [✓] │  ← 勾選框 + symbol + 已下載標記
│   2025-06-02 12:00         │  ← 案例時間
│   4h | Positive            │  ← timeframe | 標籤
│   [查看圖表]               │  ← 操作按鈕
└────────────────────────────┘
```

**視覺狀態**：
- 未選中：灰色背景
- 滑鼠懸停：淺灰高亮
- 已選中：藍色邊框
- 當前查看：深藍背景

**互動功能**：
- 點擊案例：切換到該案例的圖表
- 勾選框：批量操作（下載、導出等）
- 排序：按時間、symbol、標籤排序
- 篩選：按timeframe、標籤篩選

### 批量操作工具列

位於案例列表底部：

```
┌────────────────────────────┐
│ 已選 5 個案例               │
│ [下載K線] [導出] [取消]    │
└────────────────────────────┘
```

**功能**：
- 批量下載K線數據
- 批量導出案例資訊
- 全選/取消全選

## 圖表控制面板

### 面板配置

位於圖表區域頂部：

```
┌────────────────────────────────────────────────┐
│ 案例: ETHUSDT 2025-06-02 12:00 (4h)           │
├────────────────────────────────────────────────┤
│ 圖表設定:                                      │
│ Timeframe: [1h ▼] [4h] [1d]                   │
│ 顯示範圍: 往前 [50] 根  往後 [20] 根          │
│                                                 │
│ 策略信號:                                      │
│ [EMA5>EMA20 ▼] [套用]  [清除信號]            │
│                                                 │
│ 操作: [重置視圖] [導出圖片] [全屏]            │
└────────────────────────────────────────────────┘
```

### 控制項說明

**Timeframe選擇器**：
- 下拉選單：1h、4h、12h、1d
- 即時切換，無需重新載入頁面
- 顯示當前選中的timeframe

**顯示範圍滑桿**：
- 往前根數：1-500可調
- 往後根數：1-100可調
- 即時更新圖表範圍
- 數字輸入框支援手動輸入

**策略選擇器**：
- 預設策略下拉清單
- 自定義策略選項（進階功能）
- 套用後顯示信號箭頭
- 可隨時清除信號

**操作按鈕**：
- 重置視圖：回到T點居中
- 導出圖片：PNG格式
- 全屏模式：隱藏側邊欄

## 圖表視覺設計

### Price K線圖

**基本元素**：
- K線：紅（跌）綠（漲）配色
- 均線：EMA5、EMA20等（可選顯示）
- 案例時間點標記：紅色垂直虛線 + 箭頭
- 策略信號箭頭：綠色向上（買入）

**視覺層次**：
```
Z-index層次（從下到上）：
1. 背景網格
2. K線本體
3. 均線
4. 案例時間點標記（紅色虛線）
5. 策略信號箭頭（綠色）
6. 游標十字線
7. 懸停資訊框
```

**案例時間點標記設計**：

```
         ▼ T (案例時間點)
         │
    ╱╲  ╱╲  │  ╱╲  ╱╲
   ╱  ╲╱  ╲ │ ╱  ╲╱  ╲
  ╱        ╲│╱        ╲
──────────────────────────
```

**標記元素**：
- 垂直虛線：紅色（#e91e63），寬度2px
- 頂部箭頭：指向T點的紅色三角形
- 文字標籤："案例時間點 T"
- 穿透所有圖表（Price/Volume/Taker）

**策略信號箭頭設計**：

```
    ↑         ↑
   ╱╲  ╱╲    ╱╲  ╱╲
  ╱  ╲╱  ╲  ╱  ╲╱  ╲
 ╱        ╲╱        ╲
──────────────────────
```

**箭頭元素**：
- 位置：K線下方
- 顏色：綠色（#4caf50）買入信號
- 大小：適中，不遮擋K線
- 懸停顯示：該點的指標數值

### Volume柱狀圖

**基本元素**：
- 柱狀圖：綠（價格上漲）紅（價格下跌）
- 案例時間點標記：同步顯示紅色虛線
- 策略信號箭頭：同步顯示於對應位置

**高度比例**：
- 約為Price圖的30%高度
- 足夠清晰但不搶主視覺

**互動同步**：
- 時間軸與Price圖完全同步
- 縮放、拖曳同步響應

### Taker Ratio線圖

**基本元素**：
- 線圖：藍色線條
- 參考線：0.5（中性線）為虛線
- 案例時間點標記：同步紅色虛線
- 策略信號箭頭：同步顯示

**Y軸範圍**：
- 固定0到1之間
- 0.5為中性分界線

**視覺意義**：
- >0.5：買盤強勢（偏綠色區域）
- <0.5：賣盤強勢（偏紅色區域）

## 圖表互動設計

### 基本操作

**滑鼠操作**：

| 操作 | 功能 | 說明 |
|------|------|------|
| 左鍵拖曳 | 移動時間軸 | 左右拖曳查看更多歷史 |
| 滾輪 | 縮放 | 放大縮小時間範圍 |
| 雙擊 | 重置視圖 | 回到T點居中 |
| 懸停K線 | 顯示詳情 | OHLCV數值、時間 |
| 懸停箭頭 | 顯示信號 | 策略條件、指標數值 |

**鍵盤快捷鍵**（可選）：

| 按鍵 | 功能 |
|------|------|
| ← → | 左右移動時間軸 |
| + - | 縮放 |
| Home | 回到T點居中 |
| F | 全屏模式 |

### 跨圖表同步

**時間軸同步**：
- 三個圖表共享同一時間軸
- 拖曳或縮放任一圖表，其他同步更新
- 游標十字線垂直對齊

**同步機制**：
- 使用共享時間狀態（React Context）
- 監聽visibleRange變化事件
- 統一的時間軸管理器

**視覺反饋**：
- 垂直對齊線穿透所有圖表
- 同一時間點的數據高亮
- 游標位置即時顯示時間

### 動態數據加載

**懶加載策略**：
```
使用者拖曳到左邊界
  ↓
檢測接近邊界（剩餘10%範圍）
  ↓
觸發加載更早的數據
  ↓
無縫追加到圖表左側
```

**載入指示**：
- 邊界顯示loading圖示
- 避免阻塞當前視圖
- 失敗時提示使用者

**性能考量**：
- 單次加載不超過200根K線
- 使用虛擬滾動技術
- 超出視圖範圍的數據釋放

## 策略信號系統

### 信號計算邏輯

**範圍限制**：
- 只在ML窗口範圍內計算（如T-72到T）
- 不計算T之後的數據
- 確保無未來函數

**計算流程**：
```
使用者選擇策略（如EMA5>EMA20）
  ↓
後端計算T-72到T範圍內的EMA5、EMA20
  ↓
判斷每根K線是否符合條件
  ↓
返回符合條件的時間點列表
  ↓
前端渲染箭頭標記
```

### 預設策略清單

**趨勢類**：
- EMA5 > EMA20（短期上升）
- EMA20 > EMA50（中期上升）
- MACD金叉（動量轉強）

**震盪類**：
- RSI < 30（超賣）
- RSI > 70（超買）
- BB下軌突破（低位）

**成交量類**：
- Volume > 2倍MA（放量）
- Taker_Ratio > 0.6（買盤強）

**組合策略**：
- EMA5>EMA20 且 RSI<70
- Volume放量 且 Taker_Ratio>0.55

### 自定義策略（進階功能）

**未來擴展**：
- 使用者可編輯策略條件
- 支援多條件邏輯運算（AND/OR）
- 儲存常用策略

## 性能優化策略

### 渲染優化

**目標**：60fps流暢體驗

**優化手段**：
- 使用Lightweight Charts（原生canvas渲染）
- 虛擬滾動：只渲染可見範圍
- 防抖處理：拖曳時降低更新頻率
- RequestAnimationFrame：同步渲染循環

### 數據加載優化

**分批加載**：
- 初始載入200根K線
- 接近邊界時再加載100根
- 避免一次載入過多數據

**快取策略**：
- 已載入的數據暫存在記憶體
- 切換案例時釋放舊數據
- LRU策略管理快取大小

### 互動響應優化

**即時反饋**：
- 操作後立即視覺反應
- 非同步操作顯示loading
- 錯誤提示清晰明確

**防止阻塞**：
- 大量計算使用Web Worker
- 分幀處理避免卡頓
- 關鍵路徑優先渲染

## 錯誤處理與邊界情況

### 數據載入失敗

**處理方式**：
- 顯示友善錯誤訊息
- 提供重試按鈕
- 不影響其他已載入的案例

**提示文字範例**：
```
無法載入K線數據
可能原因：網路問題或數據不存在
[重試] [返回案例列表]
```

### 數據不完整

**情況**：
- 案例時間點T不在HDF5數據範圍內
- 請求的timeframe無數據

**處理方式**：
- 提示使用者先下載數據
- 提供一鍵下載功能
- 顯示可用的timeframe清單

### 計算異常

**情況**：
- 策略指標計算失敗
- 數據格式錯誤

**處理方式**：
- 顯示警告訊息
- 圖表仍正常顯示（不顯示信號）
- 記錄錯誤供除錯

## 使用者操作流程

### 典型使用情境

**情境1：查看單一案例**
```
1. 從案例列表點擊案例
2. 圖表自動載入並居中顯示T點
3. 觀察K線形態和趨勢
4. 調整timeframe切換視角
5. 套用策略查看信號點
6. 拖曳圖表查看更多歷史
```

**情境2：對比多個案例**
```
1. 勾選多個案例
2. 逐一查看每個案例圖表
3. 統一套用相同策略
4. 比較信號出現的頻率
5. 導出圖表進行分析
```

**情境3：批量下載數據**
```
1. 勾選需要的案例
2. 點擊批量下載按鈕
3. 等待下載進度完成
4. 系統自動更新HDF5
5. 可立即查看圖表
```
